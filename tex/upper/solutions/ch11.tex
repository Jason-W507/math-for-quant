\chapter{第 11 章分层答案}
\label{app:ch11-solutions}

\section*{口述概念}
\begin{enumerate}[leftmargin=*]
  \item 有限维分布描述任意有限时点联合律；版本只要求每个固定时点几乎处处相等，不可区分要求除同一个零测集外整条路径相等。连续修改需要额外正则性定理，单点边缘律无法决定跨时依赖或路径粗糙度。
  \item 适应表示 $X_t$ 在 $\mathcal F_t$ 可知；可预测要求动作在发生前由过去信息决定；$\tau$ 是停止时刻要求 $\{\tau\le t\}$ 当时可判断。用当日最高价决定当日盘中成交是未来函数。
  \item 沟通关系划分类；有限闭类内状态常返，通向闭类而不能返回的状态暂留。$\pi P=\pi$ 只定义稳态；有限不可约链稳态唯一且状态正常返，再加非周期才从任意初值收敛。详细平衡蕴含稳态但不是必要条件；本例详细平衡流量为 $0.120000$。
\end{enumerate}

\section*{笔试推导}
\begin{enumerate}[leftmargin=*,start=4]
  \item 递推 $2h_i=h_{i-1}+h_{i+1}$ 说明一阶差分为常数，边界给 $h_i=i/N$。而 $m_{i+1}-2m_i+m_{i-1}=-2$，二次解配合边界得 $m_i=i(N-i)$。取 $N=4,i=2$，赌徒破产命中概率与期望时长为 $0.500000$ 与 $4.000000$。
  \item 展开平方并条件化得 $S_n^2-n$ 为鞅，且 $\langle S\rangle_2=2$。Poisson 独立增量的条件均值为 $\lambda(t-s)$，故 $N_t-\lambda t$ 为鞅；Poisson 补偿鞅的可预测二次变差为 $6.000000$。加倍下注尾部损失贡献趋于 1，财富族非一致可积。
  \item 首次达到 $a$ 后反射路径，把“到过 $a$ 且终点低于 $a$”与“终点高于 $a$”配对，得 $2\{1-\Phi(a/\sqrt t)\}$。当 $a=t=1$，反射原理给出命中概率 $0.317311$。离散监控遗漏网格点间越界，所以概率向下偏。
\end{enumerate}

\section*{数值编程}
\begin{enumerate}[leftmargin=*]
  \item 第一状态概率为 $0.6+0.4(0.5)^n$，两种算法计算同一个全概率分解。
  \item 从 $i$ 出发先到 5 的概率为 $i/5$，期望时长为 $i(5-i)$。
  \item 重复路径的频率与均值应围绕解析值波动；应检查尚未退出路径，不能把模拟截断误当成吸收。
\end{enumerate}

\section*{研究判断}
\begin{enumerate}[leftmargin=*,start=10]
  \item 先按日内时段估计 $\lambda(t)$，检查计数均值/方差、等待时间指数性和增量自相关。季节性解释后若仍聚集，比较非齐次 Poisson、Cox/Hawkes 或状态模型的滚动样本外似然与残差；同时报告数据时间戳和合并事件规则。
  \item 滚动估计同一状态定义下的转移矩阵并检验稳定性；再把库存、波动、成交量或制度变量加入状态，检查给定扩充状态后的历史是否仍有预测力。若仍有，Markov 状态摘要不充分；若结构完整但矩阵漂移，则需时变转移或再训练协议。
  \item 全样本最大收益时刻依赖未来路径，通常不满足 $\{\tau\le t\}\in\mathcal F_t$，不能直接套用可选停止。可改为预先给定的有界时间窗，或用 $\tau\wedge m$ 截断并检查 $m\to\infty$ 时的一致可积/尾部条件。
\end{enumerate}

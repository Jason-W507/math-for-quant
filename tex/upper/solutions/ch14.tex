\chapter{第 14 章分层答案}
\label{app:ch14-solutions}

\section*{口述概念}
\begin{enumerate}[nosep,leftmargin=*]
\item binary64 的机器精度是使 $1+\varepsilon>1$ 的最小数，单位舍入误差是舍入到最近时最大相对误差；ulp 随指数改变。正常数适用相对误差模型，次正规数只有渐进下溢的绝对精度，NaN/Inf/上溢也在模型外。证据中，机器精度为 $2.220\times10^{-16}$，单位舍入误差为 $1.110\times10^{-16}$。
\item 前向误差比较输出，后向误差比较使结果精确成立的邻近输入；残差是方程不满足程度。条件数属于问题，稳定性属于算法；前向误差约受两者乘积控制。
\item 一般方阵用带主元 LU；SPD 用 Cholesky；最小二乘优先 QR；秩亏、最小范数解和谱诊断用 SVD。不能只按速度选，也要检查结构前提和所需证书。
\end{enumerate}

\section*{笔试推导}
\begin{enumerate}[nosep,leftmargin=*,start=4]
\item 乘以共轭式得到 $1/(\sqrt{x+1}+\sqrt{x})$。在 $x=10^{16}$ 时，原式两项先舍入为相同数，直接相减得到 $0$；稳定改写与高精度值均为 $5.000\times10^{-9}$。
\item 若 $X=U\Sigma V^T$，则 $X^TX=V\Sigma^2V^T$，故最大、最小非零奇异值比被平方。固定实验中，正规方程把条件数从 $2.449\times10^6$ 放大到约 $6.000\times10^{12}$。
\item 由 $(A+\Delta A)(x+\Delta x)=b+\Delta b$ 忽略二阶项，可得 $A\Delta x\approx\Delta b-\Delta A x$；乘以 $A^{-1}$ 并取范数即出现 $\kappa(A)$。固定近奇异系统的条件数约为 $4.000\times10^8$，前向误差为 $1.000\times10^{-2}$，相对残差不超过 $10^{-15}$。
\end{enumerate}

\section*{数值编程}
\begin{enumerate}[nosep,leftmargin=*,start=7]
\item 对 $(10^{16},1,-10^{16})$ 显式左到右累加，普通求和得到 $0$，补偿求和与 Decimal 均得到 $1$。成对求和还需冻结树形；改变顺序就是改变浮点程序。
\item 用构造真值 $(1,1)$ 比较三条路径。QR 避免显式形成 $X^TX$；SVD 还给出有效秩。秩亏矩阵第二奇异值约 $7.32\times10^{-16}$，应报告不可识别方向而非强行解释系数。
\item 对 $(1000,1000)$，朴素指数上溢；减去最大值后，稳定 log-sum-exp 为 $1000.693147$。比较器使用 $|a-b|\le\mathrm{atol}+\mathrm{rtol}\max(|a|,|b|)$，并先拒绝 NaN/Inf。固定缩放实验中，列缩放把条件数从 $1.000\times10^9$ 降到 $1.407\times10^1$。
\end{enumerate}

\section*{研究判断}
\begin{enumerate}[nosep,leftmargin=*,start=10]
\item 冻结协方差估计，报告特征谱、有效秩、条件数和单位；比较缩放、收缩、截断与约束后权重，并对窗口和相关项做扰动。只有样本外风险与换手也稳定，才能把集中权重解释为经济信号。
\item 若合同只要求业务量级一致，可用有来源的 rtol/atol 并记录归约配置；若结果参与哈希、监管复算或回归快照，则固定分块树或使用可复现累加。不能让测试容差替代协议选择。
\item 将求解器成功解释为“达到内部停止条件”，明确结论对窗口不稳；追加 QR/SVD 或稳定分解、输入缩放、谱与扰动审计。正则化或收缩必须声明目标已改变，并重新做样本外检验与限制报告。
\end{enumerate}

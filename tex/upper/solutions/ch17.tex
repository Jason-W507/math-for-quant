\section*{口述概念}
\begin{enumerate}[leftmargin=*]
  \item 固定资本贡献采用共同分母；连续全仓收益每期更新资本，终值为各总回报因子的乘积。
  \item 需说明数据可得时间、模型选择、抽样与依赖以及成交机制；正确加减法不建立这些假设。
\end{enumerate}
\section*{笔试推导}
\begin{enumerate}[leftmargin=*]
  \item 每笔成本为 $0.002$，净贡献为 $0.018,-0.012,0.028$，总和为 $0.034$。
  \item $0.04-0.006k=0$ 得 $k=20/3$。它描述固定成交路径，不是资金容量。
\end{enumerate}
\section*{数值编程}
\begin{enumerate}[leftmargin=*]
  \item $0.018-0.012+0.014=0.020$。
  \item 阈值从 $0.0025$ 降为 $0.0001$，原先小于阈值的 $p$ 不再满足。这是条件于 $p$ 值有效且搜索族完整的判断。
\end{enumerate}

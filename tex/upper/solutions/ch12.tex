\chapter{第 12 章分层答案}
\label{app:ch12-solutions}

\section*{口述概念}
\begin{enumerate}[leftmargin=*]
\item 严格平稳约束全部有限维分布，弱平稳只约束二阶矩；遍历使时间平均收敛到总体量。白噪声只要求不相关，IID 更强；创新还要求相对指定过去信息条件均值为零。
\item AR 根在单位圆外给因果表示，MA 根在单位圆外给可逆创新。ACF/PACF 的截尾规律是总体线索；有限样本受误差、近单位根和结构变化影响。
\item 预测在观测前，滤波用截至当前数据，平滑用全样本；创新似然累加一步预测误差密度。实时策略只能使用预测与滤波量，不能使用平滑值。
\end{enumerate}

\section*{笔试推导}
\begin{enumerate}[leftmargin=*,start=4]
\item $X_t=\sum_{j\ge0}\phi^j\varepsilon_{t-j}$，故 $\gamma(0)=\sigma^2/(1-\phi^2)$、$\gamma(h)=\phi^{|h|}\gamma(0)$；本例理论方差为 $2.777778$。三步预测为 $0.512000$，预测误差方差为 $2.049600$。
\item ARMA 系数 $\psi_0=1,\psi_j=(\phi+\theta)\phi^{j-1}$。ARMA 解析方差为 $2.265625$，$\rho(1)=0.732414$；AR/MA 根模为 $1.666667,3.333333$，均在单位圆外。
\item GARCH 取期望得 $\mathbb E\sigma_t^2=\omega/(1-\alpha-\beta)=1$，持续性 $0.9$；GARCH 半衰期为 $6.578813$。$u_t=0.4u_{t-1}+e_t$ 给 $\Delta u_t=-0.6u_{t-1}+e_t$。创新对数似然为 $-4.260729$。
\end{enumerate}

\section*{数值编程}
\begin{enumerate}[leftmargin=*,start=7]
\item AR(1) 模拟矩为 $(-0.013814,2.764404,0.799071)$，只交叉验证解析 $(0,2.777778,0.8)$；ARMA 解析矩不得由同一模拟反算。
\item 随机游走时长 $1,10,100$ 的方差为 $1,10,100$；协整价差方差为 $0.428571$、调整系数 $-0.6$。水平回归 $R^2=0.344011$，差分回归 $R^2=0.000216$。
\item 三次滤波均值依次为 $0.555556$、$0.084615$ 与 $0.152494$，平滑均值为 $(0.260771,0.128118,0.152494)$。前两项不同证明平滑使用了未来观测。
\end{enumerate}

\section*{研究判断}
\begin{enumerate}[leftmargin=*,start=10]
\item 先审计特征可得时点和所有选择步骤，再做滚动/扩展窗口。随机切分 MSE 为 $1.436939$，时间切分 MSE 为 $2.226153$；前者更小是泄漏或非平稳警报。
\item Ljung--Box 不拒绝只说明所检滞后没有足够线性相关证据；还需检查平方残差、尾部、参数稳定性、真实预测损失和多模型选择偏差。AIC 也不验证交易成本或因果机制。
\item 在训练窗口内选配对与阶数，冻结后滚动估计价差和 GARCH；报告协整破裂、半衰期漂移、残差诊断、换手、价差、冲击、停牌与退出规则，并保留未参与选择的末端样本。
\end{enumerate}

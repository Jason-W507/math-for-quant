\section{从熟悉的平均数开始}

平均数是熟悉的数学工具。它怎样概括几期收益？不同的权重又会怎样改变结果？从这个小问题出发，可以逐步理解线性组合、随机变量及其期望。

\begin{example}
给定 $r_1=0.01$、$r_2=-0.02$、$r_3=0.03$，先手算
\[
  \bar r=\frac{r_1+r_2+r_3}{3}=\frac{1}{150}.
\]
这个平均数概括三期等权收益。若三期权重不同，应怎样改写？第一章将从这个问题引入凸组合。
\end{example}

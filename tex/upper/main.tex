\section{从熟悉的平均数开始}

量化研究中的公式、数值程序和经验结论承担不同职责。先手算一个三期收益平均值，再让 Python 重复这项计算，可以看见两种证据如何彼此核对；计算结果本身并不替代证明或研究判断。

目录按读者叙事组织。应用主线和理论增强线都可以从这里进入；每章开头会说明直接先修，完整依赖图和路线桥接见课程地图。

\input{tex/generated/course-map}

\begin{example}
给定 $r_1=0.01$、$r_2=-0.02$、$r_3=0.03$，先手算
\[
  \bar r=\frac{r_1+r_2+r_3}{3}=\frac{1}{150}.
\]
这个平均数概括三期等权收益。若三期权重不同，应怎样改写？第一章将从这个问题引入凸组合。
\end{example}

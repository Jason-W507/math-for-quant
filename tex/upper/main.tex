\section{为什么先建立证据链}

量化研究中的公式、数值程序和经验结论必须由不同来源互相约束。本项目的最小实验先手算三期收益平均值 $1/150$，再让 Python 计算同一统计量；程序不能自行生成自己的期望答案。

\section{上册的学习路径}

主线依次连接分析、测度与概率、统计与随机过程、优化与数值计算，最终进入研究有效性和可复现审计。课程清单记录真实先修边；目录顺序不自动等于数学依赖。

\begin{example}
给定 $r_1=0.01$、$r_2=-0.02$、$r_3=0.03$，先手算
\[
  \bar r=\frac{r_1+r_2+r_3}{3}=\frac{1}{150}.
\]
随后执行 Jupytext 文本源，只有 observed 与该独立 oracle 在声明容差内一致，实验才通过。
\end{example}

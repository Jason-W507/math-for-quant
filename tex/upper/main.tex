\section{为什么先建立证据链}

量化研究中的公式、数值程序和经验结论承担不同职责。先手算一个三期收益平均值，再让 Python 重复这项计算，可以看见两种证据如何彼此核对；计算结果本身并不替代证明或研究判断。

\begin{example}
给定 $r_1=0.01$、$r_2=-0.02$、$r_3=0.03$，先手算
\[
  \bar r=\frac{r_1+r_2+r_3}{3}=\frac{1}{150}.
\]
随后用配套程序重复计算。若显示值与手算结果一致，便可以继续阅读；更完整的误差说明和复现步骤放在线上材料。
\end{example}

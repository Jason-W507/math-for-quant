\section{分级提示}
\begingroup\small
\begin{enumerate}[nosep,leftmargin=*]
\item 从弦、一阶下界和统一 Hessian 下界分别判断；次梯度处理不可微点。
\item 先问问题是否凸，再问局部最优是否满足资格条件；Slater 面向凸强对偶。
\item 先写 $q\le L\le f$；影子价格是最优值对约束右端项的局部导数。
\item 反证主约束不活跃会得到不可行零点，再由驻点和互补求解。
\item 写成 $p^*(b)=b^2/4$；检查约束写法决定导数与乘子的符号。
\item 对 $w^T\Sigma w+\nu(1-\mathbf1^Tw)$ 求导，再归一化预算。
\item 投影只保持可行；证书必须从最终候选解重新计算。
\item 用中心差分而非优化器内部乘子复述解析答案，并冻结步长与容差。
\item 同时报告权重、方差、条件数和扰动后差异，避免只看目标值。
\item 依次检查目标单位、协方差谱、活跃约束、输入扰动与停止容差。
\item 固定费用与整数条件破坏凸组合封闭性，通常转为混合整数问题。
\item 冻结估计窗口与约束，提交 KKT/对偶证书、扰动、成本和失败状态。
\end{enumerate}
\endgroup

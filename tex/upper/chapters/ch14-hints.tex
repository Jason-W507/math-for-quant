\section{分级提示}
\begingroup\small
\begin{enumerate}[nosep,leftmargin=*]
\item 从 $1+\varepsilon>1$、相邻浮点间距和渐进下溢分别解释；不要混淆 $2^{-52}$ 与 $2^{-53}$。
\item 条件性属于精确映射，稳定性属于算法；残差通常更接近后向证据。
\item 先看矩阵结构和研究问题：SPD、一般方阵、最小二乘、秩亏分别对应不同分解。
\item 乘以共轭式；失败发生在两个大数分别舍入之后。
\item $X$ 的奇异值为 $\sigma_i$，$X^TX$ 的特征值为 $\sigma_i^2$。
\item 把 $A\Delta x\approx\Delta b$ 与 $A^{-1}$ 的范数界结合，再分清残差属于哪个右端项。
\item 固定输入顺序并保留所有算法输出；高精度路径不能复用 float64 累加。
\item 用构造的真系数生成 $y$，再加冻结扰动；不要只比较训练残差。
\item 先减最大值；比较器同时用 atol 与 rtol，并显式拒绝非有限值。
\item 报告谱、有效秩、单位、缩放和输入扰动；正则化结果必须另做样本外验证。
\item 区分业务容差与审计协议；确定性归约会付出吞吐或实现复杂度成本。
\item 将“成功”降级为数值求解状态，提交窗口扰动、替代分解、缩放/收缩与限制说明。
\end{enumerate}
\endgroup

\subsection*{分级提示}
\begingroup\small
\begin{enumerate}[nosep,leftmargin=*]
  \item \textbf{口述概念：}先固定时间点，再固定样本状态；滤过决定条件期望中的信息。
  \item \textbf{笔试推导：}解 $\pi P=\pi$ 与 $\pi\mathbf1=1$；展开 $(S_n+\xi_{n+1})^2$ 后条件化。
  \item \textbf{数值编程：}矩阵幂和解析矩不能由模拟回算；Brownian 协方差目标是 $\min(s,t)$。
  \item \textbf{研究判断：}检查分时强度、过度离散、自相关、等待时间分布与样本外稳定性。
\end{enumerate}
\endgroup

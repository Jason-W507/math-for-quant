\subsection*{分级提示}
\begingroup\small
\begin{enumerate}[nosep,leftmargin=*]
  \item \textbf{口述概念：}seed 管可重放性，标准误管抽样波动，独立 oracle 管实现正确性。
  \item \textbf{笔试推导：}先把均值方差写成协方差双重和；控制变量对 $\beta$ 的方差是二次函数。
  \item \textbf{数值编程：}用解析积分验收模拟；bootstrap 小样本可用笛卡尔积完全枚举。
  \item \textbf{研究判断：}先识别被重抽样的独立单位，再选择 block 或 cluster，而不是先调重复次数。
\end{enumerate}
\endgroup

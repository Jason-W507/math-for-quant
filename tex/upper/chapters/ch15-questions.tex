\section{四级问题与即时练习}
\begingroup\small
\begin{enumerate}[nosep,leftmargin=*]
  \item \textbf{口述概念：}为什么固定 seed 不等于 Monte Carlo 结果正确？区分标准误、偏差与实现错误。
  \item \textbf{笔试推导：}推导 $\operatorname{Var}(\hat\mu_N)=\sigma^2/N$ 和控制变量的 $\beta^*$；对 $U^2$ 算出理论方差缩减倍数。
  \item \textbf{数值编程：}用解析积分、两个样本量和独立 seeds 验收 $N^{-1/2}$ 误差率；穷举 $(1,2,4)$ 的全部 bootstrap 均值。
  \item \textbf{研究判断：}对有自相关的日收益直接逐日 bootstrap 后得到很窄的 Sharpe 区间，结论为何不可信？设计替代证据。
\end{enumerate}
\endgroup

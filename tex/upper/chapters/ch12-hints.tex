\section{分级提示}
\begingroup\small
\begin{enumerate}[nosep,leftmargin=*]
\item 平稳约束分布或二阶矩；遍历连接时间平均与总体；创新绑定信息集。
\item 写出 $1-\phi z$ 与 $1+\theta z$；总体截尾规律不等于样本定阶保证。
\item 平滑使用未来数据，实时边界只能到滤波值。
\item 反复代入 AR(1)，再用创新与过去正交。
\item 使用 MA$(\infty)$ 系数 $\psi_0=1,\psi_j=(\phi+\theta)\phi^{j-1}$。
\item GARCH 对方差取期望；ECM 对 $u_t=\rho u_{t-1}+e_t$ 作差；Kalman 累加高斯创新密度。
\item 解析矩先于模拟，容差来自抽样误差而非结果需要。
\item 随机游走方差随 $t$ 增长；协整价差应在滚动窗口保持均值回复。
\item 保存每步预测均值/方差；反向平滑只用于事后估计。
\item 冻结可得时点、定阶与参数，再用滚动外层评估。
\item 检查残差平方、尾部、参数漂移和真实预测损失。
\item 配对选择必须在训练集内；样本外同时计入换手、冲击和失效退出规则。
\end{enumerate}
\endgroup

\section*{章末练习}
\begingroup\small
\subsection*{口述概念}
\begin{enumerate}[nosep,leftmargin=*]
  \item 区分样本空间、事件、随机变量、分布、CDF、PMF 和密度；为什么密度可以大于一？
  \item 解释 LOTUS、推前测度和变量变换公式之间的关系，并说明非单调变换为何要合并原像。
  \item 区分不相关、独立、同分布和 IID；说明每个概念需要哪些矩或联合信息。
\end{enumerate}

\subsection*{笔试推导}
\begin{enumerate}[nosep,leftmargin=*]
  \item 由固定有限记录推导 CDF、均值、方差和 $X^2$ 的推前分布。
  \item 给定固定 $2\times2$ 联合表求边缘、协方差、相关系数和独立性差；构造零相关但不独立的例子。
  \item 推导 Lognormal 的密度、均值和方差；证明 Pareto$(\alpha)$ 的 $p$ 阶矩当且仅当 $p<\alpha$ 时有限。
\end{enumerate}

\subsection*{数值编程}
\begin{enumerate}[leftmargin=*]
  \item 用逆分布抽样生成三点分布，比较经验均值与解析矩。
  \item 将样本平方，合并相同取值的概率质量。
  \item 模拟 $U(-1,1)$ 的平方并比较解析 CDF 与中位数。
\end{enumerate}

\subsection*{研究判断}
\begin{enumerate}[nosep,leftmargin=*]
  \item 观察到零相关时，哪些额外信息才能支持独立性？请用联合分布或反例说明。
  \item 为什么有限样本中的经验分布、解析分布和抽样估计不能混为同一个对象？
\end{enumerate}

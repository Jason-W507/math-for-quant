\section{四级问题与即时练习}
\begingroup\small
\subsection*{口述概念}
\begin{enumerate}[nosep,leftmargin=*]
  \item 定义几乎处处、依概率、$L^p$ 与分布收敛；哪些定义需要随机变量位于同一概率空间？
  \item 画出有效蕴含图，解释一致可积性为何是“依概率升级到 $L^1$”的关键尾部条件。
  \item 区分 WLLN、SLLN、经典 iid CLT、Berry--Esseen 界与集中不等式分别回答的问题。
\end{enumerate}

\subsection*{笔试推导}
\begin{enumerate}[nosep,leftmargin=*]
  \item 用 Markov 证明 $L^p\Rightarrow\mathbb P$，再证明依概率收敛的子列刻画。
  \item 对 iid 有限方差变量用 Chebyshev 推导 WLLN；对 Bernoulli$(0.3)$、$n=200$ 推导标准误和三种集中界。
  \item 写出经典 CLT 的特征函数证明骨架，并计算 Bernoulli 的三阶绝对中心矩与 Berry--Esseen 上界。
\end{enumerate}

\subsection*{数值编程}
\begin{enumerate}[nosep,leftmargin=*]
  \item 实现打字机、稀有尖峰与 $L^1$ 非 $L^2$ 三个反例记录，逐项报告偏差概率和矩。
  \item 精确枚举二项尾概率与标准化 CDF 距离；独立计算 Chebyshev、Hoeffding、Bernstein 和 Berry--Esseen 界。
  \item 用固定种子复现 Bernoulli 与 Cauchy 实验，并注入伪造尾概率、放宽容差、改变 canonical 设计和完全依赖方差。
\end{enumerate}

\subsection*{研究判断}
\begin{enumerate}[nosep,leftmargin=*]
  \item 日频策略使用 20 日重叠收益却按 iid 报告 CLT 区间。应如何重定义抽样单位、诊断依赖并给出稳健证据？
  \item 一个稀有违约模型给出对称正态区间且下界为负。为什么“大样本渐近”仍可能误导？应改用什么验证？
\end{enumerate}
\endgroup

\subsection*{分级提示}
\begingroup\small
\begin{enumerate}[nosep,leftmargin=*]
  \item \textbf{口述概念：}随机变量是映射；分布是该映射把概率测度推到目标空间后的结果。
  \item \textbf{笔试推导：}先检查四格总质量，再逐行、逐列求和；把联合格与边缘乘积比较。
  \item \textbf{数值编程：}不要抽样；直接计算 $M_B(\log2)$、$G_N(1/2)$、$M_Z(1/2)$ 与 $\log M$。
  \item \textbf{研究判断：}检查 QQ 图、尾指数、阈值稳定性、极端事件来源及结论对分布族的敏感性。
\end{enumerate}
\endgroup

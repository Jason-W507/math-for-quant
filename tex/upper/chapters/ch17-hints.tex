\subsection*{分级提示}
\begingroup\small
\begin{enumerate}[nosep,leftmargin=*]
  \item \textbf{口述概念：}哈希只证明字节身份；复现只证明映射稳定；统计和交易结论各有额外假设。手算必须与被测实现独立。
  \item \textbf{笔试推导：}先写同资本基数、固定成本和完整假设族；时间谓词是内容条件，不是文件属性；逐步跟踪 $10^{16}+1$ 的舍入。
  \item \textbf{数值编程：}干净包通过显式 package root；泄漏 fixture 要同步更新哈希；限制篡改保持项目数，隔离哈希门禁。
  \item \textbf{研究判断：}每个“可以声称”必须能指到命令和输出；每个“不可声称”应指向限制报告或缺失的方向证据。
\end{enumerate}
\endgroup

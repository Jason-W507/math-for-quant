\subsection*{分级提示}
\begingroup\small
\begin{enumerate}[nosep,leftmargin=*]
  \item \textbf{口述 1：}前三种比较共同空间上的差；分布收敛只比较概率律和连续点。
  \item \textbf{口述 2：}主链是 a.s.$\Rightarrow\mathbb P\Rightarrow d$；$L^p$ 经 Markov 进入概率收敛；尾部质量决定能否进入 $L^1$。
  \item \textbf{口述 3：}LLN 说中心，CLT 说缩放后的形状，Berry--Esseen 说误差，集中界说有限样本尾概率。
  \item \textbf{推导 1：}先对 $|X_n-X|^p$ 用 Markov；子列按 $2^{-k}$ 同时控制阈值和失败概率。
  \item \textbf{推导 2：}$\operatorname{Var}(\bar X_n)=\sigma^2/n$；Bernstein 分母同时含方差与幅度项。
  \item \textbf{推导 3：}中心化特征函数在零点作二阶展开；Bernoulli 的 $\rho_3=p(1-p)^3+(1-p)p^3$。
  \item \textbf{编程 1：}反例要输出解析概率与矩，不用有限模拟替代极限证明。
  \item \textbf{编程 2：}在每个二项跳点同时比较 CDF 的左极限和右值，才能得到离散分布的 sup 距离。
  \item \textbf{编程 3：}理论 expected 来自独立账本；坏标签只能写临时 fixture，脚本必须给稳定诊断。
  \item \textbf{研究 1：}重叠收益共享观测；比较非重叠抽样、HAC、块重采样和块长敏感性。
  \item \textbf{研究 2：}先看 $np$ 与边界；同时报告精确二项概率、覆盖率和参数空间约束。
  \item \textbf{研究 3：}滚动报告位置、尺度、尾部和自相关；稳定均值可能只是制度混合后的平均。
\end{enumerate}

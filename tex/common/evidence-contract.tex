\section*{如何使用本书}

本书每章围绕一个问题展开。正文先定义数学对象并给出推导，再用一个可以手算的例子检验直觉，最后讨论它在量化研究中的用途与局限。配套 Python 实验用于核对计算、观察有限样本现象；它与数学证明承担不同职责。

阅读时可以沿应用主线直接进入线性代数、概率统计、时间序列、优化和数值计算；希望理解理论基础的读者，则可以完整学习分析、测度和随机过程。章末练习分别训练概念解释、公式推导、数值实现和研究判断，完整答案收录在共享答案册中。

\begin{description}
  \item[定理与证明] 给出数学对象、假设、结论以及证明或反例。
  \item[计算实验] 用手算、解析解、枚举或独立算法核对一个透明实现，并说明误差口径。
  \item[失败边界] 展示条件失效、数值不稳定或研究设计改变时会发生什么。
  \item[研究连接] 说明结论如何进入量化问题，以及哪些外推仍然没有根据。
\end{description}

这些标记只提示本章新增的阅读重点。项目的完整证据约定、文件布局和自动化检查见仓库中的 \path{docs/evidence-contract.md}；它们服务于维护者和复现者，不要求读者先学习项目管理流程。

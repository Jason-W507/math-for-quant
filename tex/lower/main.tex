\chapter{六条方向路线}

\section{共同研究门禁}

所有路线都必须检查时间泄漏、多重检验、样本外设计、交易成本与制度摩擦、数值稳定和可复现性。模型更复杂不能替代这些研究证据。

\section{路线入口}

\begin{enumerate}
  \item 多因子与计量：从横截面信号到成本和容量；
  \item 时间序列与统计套利：从动态模型到 walk-forward 验证；
  \item 机器学习 Alpha：从泛化到漂移与校准；
  \item 衍生品：从鞅与 It\^o 公式到定价和对冲；
  \item 组合与风险：从协方差到稳健优化和压力测试；
  \item 高频与执行：从订单流到事件时间仿真和控制。
\end{enumerate}

\begin{note}
每条路线的 Capstone 是学习证据，不代表生产部署、实盘业绩或团队经验。
\end{note}

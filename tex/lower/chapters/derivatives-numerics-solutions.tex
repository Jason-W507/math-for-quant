\chapter{定价、校准与对冲答案}
\begin{enumerate}
  \item 树主要有时间离散；PDE 有空间、时间和边界截断；Monte Carlo 有采样误差；三者都共享参数和模型错设。
  \item $m$ 个报价各配一个 $\sigma_j$ 时有 $m$ 个自由参数，逐点残差接近零不说明低维曲面解释了报价。参数曲面用少量共享参数同时重定价全部节点。
  \item 对内部节点 $i$，$a_i=(\sigma^2i^2-ri)/2,b_i=-\sigma^2i^2-r,c_i=(\sigma^2i^2+ri)/2$；隐式层使用下、主、上对角 $-\Delta ta_i,1-\Delta tb_i,-\Delta tc_i$。
  \item 离散凸函数的割线斜率非降：$(C_i-C_{i-1})/(K_i-K_{i-1})\le(C_{i+1}-C_i)/(K_{i+1}-K_i)$。只有步长相等时才化为常见二阶差分。
  \item 固定示例闭式为 $8.916037$，树和 PDE 为 $8.908302,8.908382$。实验应分别固定另外两个维度，记录误差是否进入平台区；平台可能来自未加密的维度。
  \item 透明与 sklearn 恢复 $(0.035,0.080,0.006)$，系数差为 0，最大价格误差约 $1.42\times10^{-14}$。真实数据不应期待这种由生成模型保证的零残差。
  \item 分红、负利率或远期变化会破坏未经归一化的固定执行价期限比较。应改用与适用假设一致的远期/贴现表示，或显式跳过该检查。
\end{enumerate}

\section*{逐题推导与核对}
\begin{enumerate}[leftmargin=*]
  \item 树把连续时间和状态空间离散化，误差来自 $\Delta t$、节点截断和插值；PDE 还增加空间步长 $\Delta S$、边界条件和线性系统求解误差；Monte Carlo 的主要随机误差为 $s/\sqrt N$，路径依赖产品还会有时间离散误差。三者共享输入曲线、波动率和支付函数的模型错设，因此网格加密不能修复错误参数。
  \item 逐点反演让每个报价 $j$ 都有自己的 $\sigma_j$，自由度与报价数相同，残差自然可以接近零。参数曲面则设 $\sigma(K,T)=g(K,T;\vartheta)$，先用一组共享参数 $\vartheta$ 同时重定价所有节点，再留出未参与拟合的节点检查外推。两者都可能有小训练残差，但后者才提出低维结构假设。
  \item 对内部节点写显式空间算子 $\mathcal L V=a_iV_{i-1}+b_iV_i+c_iV_{i+1}$，其中
  \[
  a_i=\tfrac12(\sigma^2i^2-ri),\quad b_i=-\sigma^2i^2-r,\quad c_i=\tfrac12(\sigma^2i^2+ri).
  \]
  后向 Euler 为 $(I-\Delta t\mathcal L)V^{n+1}=V^n$，所以三对角行的系数是 $-\Delta t a_i$、$1-\Delta t b_i$、$-\Delta t c_i$。边界项移到右侧；若把符号或时间方向写反，稳定性和价格都会错。
  \item 在不等距执行价 $K_{i-1}<K_i<K_{i+1}$ 上，凸性要求相邻割线斜率满足
  \[
  \frac{C_i-C_{i-1}}{K_i-K_{i-1}}\le
  \frac{C_{i+1}-C_i}{K_{i+1}-K_i}.
  \]
  这是离散二阶导数非负的定义；只有 $K_i-K_{i-1}=K_{i+1}-K_i=h$ 时才可写成 $C_{i-1}-2C_i+C_{i+1}\ge0$。期限单调性还要先统一贴现和远期口径。
  \item 做误差表时一次只加密一个维度：固定 $(M,S_{\max})$ 改 $N_t$，固定 $(N_t,S_{\max})$ 改 $M$，固定 $(M,N_t)$ 改边界。每一行同时记录价格、绝对误差、相邻细化差和运行时间；若相邻差不再下降，应检查未加密维度、边界污染或线性求解容差。闭式值 $8.916037$ 是独立参照，不能从 PDE 输出反推。
  \item 参数化总方差先用独立曲面参数恢复得到 $(0.035,0.080,0.006)$，再把它们送入定价器计算价格残差。报告应分成“系数误差”和“价格误差”两列：前者检验优化/校准实现，后者检验模型到报价的传播。合成 fixture 中最大价格差约 $1.42\times10^{-14}$ 只说明双实现一致，不意味着真实市场曲面也能零残差。
  \item 固定执行价的日历单调性依赖同一标的、同一收益口径、非负利率/分红和无套利边界。分红、负利率、远期变化或报价来自不同清算时点时，直接比较 $C(K,T_1)$ 与 $C(K,T_2)$ 可能把经济变化误报为违反单调性。应比较贴现后的远期标准化价格，或在协议中标记该检查不适用并说明原因。
\end{enumerate}

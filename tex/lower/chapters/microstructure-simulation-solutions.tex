\MFQTransition{事件时间仿真答案}

\begin{enumerate}[leftmargin=*]
  \item 对同一事件流运行策略 $A,B$，差值方差为
  \[
  \operatorname{Var}(Y_A-Y_B)=\operatorname{Var}(Y_A)+\operatorname{Var}(Y_B)-2\operatorname{Cov}(Y_A,Y_B).
  \]
  当共享外生随机数使两策略结果正相关时，配对差的方差小于独立比较；负相关时则可能相反。共享的是底层随机数，各策略仍按自己的报价决定成交。模型错设也不会随模拟次数增加而消失。
  \item 用现金与持仓定义损益可避免买卖符号混淆。令 $v_i$ 为做市商在事件 $i$ 的有符号成交量（买入为正），$P_i$ 为成交价，$m_i$ 为事件后的中间价。现金与库存满足 $C_i=C_{i-1}-v_iP_i$、$Q_i=Q_{i-1}+v_i$，组合价值为 $V_i=C_i+Q_im_i$。因此 $V_i-V_{i-1}=Q_{i-1}(m_i-m_{i-1})+v_i(m_i-P_i)$。前项为旧库存重估，后项为成交相对中间价的贡献；全路径将这些增量相加，期末库存估值已包含在 $V_T$ 中。
  \item 对每条完整路径记录 PnL、期末库存和最大绝对库存。均值可用路径样本标准误的 t 区间，尾部则给百分位 bootstrap 或直接报告 P5/P95；比较两个控制器时优先用成对差区间。这些区间以独立完整路径为抽样单位；共同随机数通过两种结果的协方差影响差值的不确定性。
  \item 先选分段常数强度 $\lambda(t)=\lambda_k$，用时间变换 $z_i=\int_{t_{i-1}}^{t_i}\lambda(u)du$。若模型正确，$z_i$ 应近似 IID Exp(1)，所以检查均值、方差、QQ 图和残差自相关；若仍有日内模式，说明强度或事件定义遗漏结构。
  \item 若把同一次买入重复计算，现金会被多扣一次，库存也被多加一次；若把未来成交提前到决策之前，策略就使用了原本未知的信息。可以逐个事件手算现金与库存，定位最先与原事件记录不一致的时刻。订单编号只帮助辨认事件，数学上需要保留的是成交次数、数量与发生顺序。
  \item 单路径 PnL 既没有抽样误差，也不能揭示库存尾部和成交失败。正确报告要固定配置、生成多路径分布、分解交易数/费用/冲击、给出基线与压力场景，并说明参数是否由同一批路径选择。
  \item SEC 聚合 cancel-to-trade 只告诉市场层面的事件数量比，缺少自己的订单到达序号、前方量、隐藏量、撤单时延和撮合规则。不同队列状态可以产生相同聚合比，因此自己的成交概率不可识别；最多把它当外部先验或压力参数。
  \item 从小型订单簿出发，让各策略依据当前库存报价，再根据报价与同一外生市场情形决定成交。比较多条路径的损益差、期末库存和最大库存。静态策略收益较高时，还需判断这种差异是否伴随更高库存风险，以及是否大于模拟波动。
\end{enumerate}

\subsection*{基础衔接：独立计算}
只能说明两策略在该仿真机制下没有差别。二者可能都亏损，也可能共享同一个错误成交假设。

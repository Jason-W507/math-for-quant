\chapter{机器学习与 AI Alpha 提示}
\begin{enumerate}[leftmargin=*]
  \item 分清训练样本平均、未来分布期望和复杂度惩罚。
  \item 分别对应损失、概率刻度和模型依赖集合。
  \item 对每个预测误差平方后取均值。
  \item 使用 $(p-y)^2$，不要改用分类准确率。
  \item mask 只覆盖 padding；目标日期必须晚于窗口末端。
  \item 逐笔列毛收益与成本。
  \item 三者都把选择阶段之后的信息送回模型。
  \item 依据漂移类型、校准失败和业务成本冻结响应。
\end{enumerate}

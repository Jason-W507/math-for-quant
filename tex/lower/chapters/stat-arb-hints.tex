\chapter{时间序列与统计套利提示}
\begin{enumerate}[leftmargin=*]
  \item 从条件均值、二阶不相关和可预测误差三个层次区分。
  \item 先问线性组合是否平稳，再问成本、容量和结构稳定性。
  \item 把 $X_t=0.6X_{t-1}$ 直接代入分子。
  \item 先算创新方差，再算增益。
  \item 阈值越低通常越早，也更易误报。
  \item 成本必须逐笔进入，不得从毛收益乘一个比例猜测。
  \item 两者都让未来分布信息进入过去模型。
  \item 只用当时可见残差和状态概率触发停用。
\end{enumerate}

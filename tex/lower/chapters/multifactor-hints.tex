\chapter{多因子与计量提示}
\begin{enumerate}[leftmargin=*]
  \item 先分别写出三个目标量的条件期望或结构参数。
  \item 比较原始值线性相关与秩变换后的相关。
  \item 标准误使用两期斜率的样本方差再除以 $T$。
  \item 写 $x^\perp=(I-P_Z)x$，使用 $Z^T(I-P_Z)=0$。
  \item 手工指定第三期斜率；不要让程序生成期望值。
  \item 三类失败应分别来自时间协议、条件数和独立 oracle。
  \item BH 只控制选择集合的统计错误比例，不验证衰减、摩擦或容量。
  \item 逐项核对时点数据、可交易集合与交易台账。
\end{enumerate}

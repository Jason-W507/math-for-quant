\section{树模型综合练习}
\begin{enumerate}[leftmargin=*]
  \item \textbf{口述概念：}为什么树模型是量化表格数据的主力基线？它相对线性模型和神经网络分别获得与失去什么？
  \item \textbf{口述概念：}CART、随机森林、gradient boosting 与 XGBoost 的随机化或优化对象有何不同？
  \item \textbf{笔试推导：}对样本 $x=(-2,-1,1,3)$、$y=(-4,-2,1,5)$，计算三个 CART 候选阈值的平方误差并选最优分裂。
  \item \textbf{笔试推导：}由 XGBoost 的二阶近似推导叶权重 $w_j^*=-G_j/(H_j+\lambda)$。
  \item \textbf{数值编程：}在同一 walk-forward 切分上比较单树、随机森林、gradient boosting 和 MLP，保存训练时间、验证损失、净收益与换手。
  \item \textbf{研究判断：}审计一个随机切分资产--日期行、再报告高 AUC 的树模型研究材料。
\end{enumerate}

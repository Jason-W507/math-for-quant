\chapter{投资组合与风险管理答案}
\begin{enumerate}[leftmargin=*]
  \item 半正定只保证 $w^\top\Sigma w\ge0$；很小的正特征值仍会造成巨大条件数，使逆矩阵和权重对采样误差极敏感。
  \item $\sum_i\mathrm{RC}_i=\sum_iw_i(\Sigma w)_i=w^\top\Sigma w$。若使用波动率贡献，再整体除以组合波动率。
  \item 对角矩阵下 $\mathrm{RC}_i=w_i^2\sigma_i^2$。令贡献相等得 $w_i\sigma_i=k$，归一化后 $w_i=\sigma_i^{-1}/\sum_j\sigma_j^{-1}$。
  \item $\lambda$ 从 0 到 1 时，矩阵向目标移动。图中应同时报告最小特征值、条件数和最终风险贡献；不能只挑权重最平滑的强度。
  \item 对起点 $b$ 抽取 $(r_b,r_{b+1},r_{b+2},r_{b+3})$，循环或只取合法区块，再拼到原样本长度。区块长度也要做敏感性分析。
  \item 可构造三资产、三日期且每一对资产只共享不同两日的数据。逐对相关都可能看似合理，但拼接矩阵的某个特征值为负。
  \item 因子模型在 $n/T$ 大时用结构降低方差；若遗漏流动性、行业或非线性因子，低维稳定性会以系统性偏差为代价。
  \item 合格协议列出资产进入/退出规则、交易日交集、时区、公司行动、收益公式、缺失值、异常值、估计窗口与信息可用时点。
\end{enumerate}

\section*{逐题推导与核对}
\begin{enumerate}[leftmargin=*]
  \item 半正定只保证所有方向的方差非负；若最小特征值 $\lambda_{\min}$ 很小，条件数 $\lambda_{\max}/\lambda_{\min}$ 很大，逆矩阵会放大样本噪声。先报告特征值和条件数，再比较扰动后的权重/风险；“没有负特征值”不能代替稳定性证据。
  \item 定义边际风险 $m=\Sigma w$，美元风险贡献为 $\mathrm{RC}_i=w_im_i$。逐项相加得 $\sum_iw_i(\Sigma w)_i=w^T\Sigma w=\sigma_p^2$；若报告波动贡献，则 $\mathrm{RC}^{(\sigma)}_i=w_im_i/\sigma_p$，总和为 $\sigma_p$。负权重时贡献可为负，必须说明口径。
  \item 对角协方差下 $\sigma_p^2=\sum_iw_i^2\sigma_i^2$，边际风险为 $w_i\sigma_i^2$，所以贡献为 $w_i^2\sigma_i^2$。令三项相等，得到 $|w_i|\sigma_i$ 相等；在长仓约束下取 $w_i\sigma_i=k$，用 $\sum_iw_i=1$ 得 $k=(\sum_j\sigma_j^{-1})^{-1}$，故 $(w_1,w_2,w_3)=(6,4,3)/13$。
  \item 收缩矩阵写成 $\Sigma_\lambda=(1-\lambda)\widehat\Sigma+\lambda T$。对每个 $\lambda$ 计算最小特征值、条件数、解权重、组合波动和预算差；若权重更平滑但条件数仍高，不能只凭图选择强度。oracle 的透明实现与库实现应在同一矩阵上逐元素比较。
  \item 移动区块 bootstrap 从起点 $b$ 取连续 $(r_b,\ldots,r_{b+3})$，允许循环时对越界索引取模，重复抽取直至长度恢复。每个重采样计算协方差、权重和风险；改变区块长度 1、4、8，观察区间对依赖结构的敏感性，不能把 IID 重采样当默认真值。
  \item 三资产三日期的成对删除可使每个二维子矩阵都看似半正定，但不同成对样本拼接后不再来自同一个联合分布。明确给出拼接后的 $3\times3$ 矩阵，计算特征值并指出负值；修复是统一观测交集、使用 PSD 投影或声明估计失败，而不是仅把负值截为零。
  \item 因子模型用少量因子降低 $n/T$ 高时的估计方差，但遗漏流动性、行业、非线性或跳跃会产生系统性偏差。比较时同时报告样本协方差和因子模型的样本外风险、残差因子暴露、极端压力和换手，不能只看谱是否更稳定。
  \item 真实收益协议需固定资产进入/退出、交易日交集、时区、公司行动、复权、缺失/停牌处理、异常值、估计窗口和点时可得时间。每个过滤都记录行数变化和原因，确保最终资产池不是由未来可见性选择出来的。
\end{enumerate}

\chapter{随机分析与无套利分层答案}
\begin{enumerate}
  \item 定理陈述为网格宽度趋零时二次变差依概率收敛到 $T$；有限模拟只给一个随机实现；离散平方恒等式则在每个有限网格精确成立。
  \item $H_{t_i}$ 必须由 $\mathcal F_{t_i}$ 决定，不能读取 $W_{t_{i+1}}-W_{t_i}$ 后再选方向，否则积分把未来信息伪装成策略。
  \item 由 $W_{i+1}^2-W_i^2=2W_i\Delta W_i+(\Delta W_i)^2$ 求和，再令网格细化，二次变差项趋于 $T$。
  \item $f'(s)=1/s,f''(s)=-1/s^2$，故 $\mathrm d\log S_t=(\mu-\sigma^2/2)\mathrm dt+\sigma\mathrm dW_t$，积分得解析终值。
  \item 冻结实验的 block size 64、16、1 对应 $1.164390,1.132000,1.012519$；它展示同一路径的嵌套细化，不承诺单调。
  \item $\theta=(0.08-0.02)/0.2=0.3$，所以 $0.08-0.2(0.3)=0.02$；换成 $-0.3$ 会得到 0.14 并触发诊断。
  \item 确定性能量 100 给出 $e^{100}<\infty$。固定上限是风险政策，不是 Novikov；终端奇点的对数能量才随 cutoff 消失而发散。
  \item Novikov 是保证随机指数为真鞅的充分条件之一。检查失败只说明该证明路线失效，还需其他鞅条件或反例才能判断结论。
\end{enumerate}

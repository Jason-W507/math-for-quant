\chapter{表格统计学习提示}
\begin{enumerate}[leftmargin=*]
  \item 从非线性、交互、缺失处理和样本效率回答，同时强调树不学习序列表示。
  \item CART 贪心分裂；森林 bootstrap 加特征随机化；boosting 拟合负梯度；XGBoost 使用二阶近似与结构正则。
  \item 候选为 $-1.5,0,2$，分别计算左右均值与 SSE。
  \item 对单个叶的 $G_jw+\frac12(H_j+\lambda)w^2$ 求导。
  \item 所有模型共用外层测试和仓位映射，不能各挑最佳窗口。
  \item 查同一资产相邻日期和重叠标签是否跨越切分。
\end{enumerate}

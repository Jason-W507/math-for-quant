\chapter{组合与风险分层答案}
\begin{enumerate}[leftmargin=*]
  \item $a^\top\Sigma a=\operatorname{Var}(a^\top r)\ge0$。正特征值也可能相差许多数量级，使逆和权重对估计误差极敏感。
  \item 最小方差只最小化总方差；均值--方差权衡期望收益与方差；风险平价平衡预先定义的风险贡献。
  \item 展开 $(x,1-x)\Sigma(x,1-x)^\top$ 并求导，得 $x^*=(\sigma_2^2-\sigma_{12})/(\sigma_1^2+\sigma_2^2-2\sigma_{12})$，随后投影到 $[0,1]$。
  \item 目标为 $\mu^\top w-\gamma w^\top\Sigma w/2-c\lVert w-w^-\rVert_1$；约束包括满仓、长仓、上限和不可交易资产不变。非零 KKT 乘子标识活跃约束。
  \item 本章在 ridge 为 0 和 0.0075 时分别得到 $(0.727273,0.272727)$ 与 $(0.7,0.3)$；曲线应报告输入单位和组合风险，而非只画权重。
  \item 枚举得到 $(0.6,0.4)$。双边换手为 $|0.6-0.4|+|0.4-0.6|=0.4$，单边口径为 0.2；十万元、费率 0.001 的双边成本为 40。
  \item 历史法受样本与制度变化限制，参数法受分布错设限制，压力测试回答指定情景而不提供发生概率；三者应并列而非互相背书。
  \item 令第一资产不可交易，再提出改变其权重的方案；系统应给出稳定诊断。恢复可以冻结该权重并重优化其余资产，若可行域为空则明确停止。
\end{enumerate}

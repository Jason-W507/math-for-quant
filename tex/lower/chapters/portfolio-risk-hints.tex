\chapter{组合与风险提示}
\begin{enumerate}[leftmargin=*]
  \item 考察任意 $a^\top r$ 的方差；再区分代数可逆与统计条件数。
  \item 比较是否使用期望收益、风险贡献还是总方差。
  \item 令 $w=(x,1-x)$ 后对一元二次式求导，并检查边界。
  \item 把交易成本写进目标，把可交易性和权重上限写进可行域。
  \item 固定其他输入，只改变对角线正则项；同时记录条件数。
  \item 手工列出 0.1 网格的可行点，不调用被测优化函数生成答案。
  \item 三者分别依赖历史经验、分布假设和条件情景。
  \item 不可交易资产权重保持不变；若无可行解，应拒绝而非静默裁剪。
\end{enumerate}

\MFQTransition{尾部与压力风险答案}
\begin{enumerate}[leftmargin=*]
  \item VaR/ES 描述分布尾部；历史压力重演已知联合冲击；假设压力评估指定条件；反向压力寻找触发资本或流动性阈值的冲击尺度。
  \item 若尾部质量不是整数，积分分位数把边界观察按剩余概率质量加权，再除以总尾部质量；这避免随意全纳入或全排除。
  \item 代入 $sx$ 得 $L(sx)=-s d^\top x-s^2\sum_i g_ix_i^2/2$。令其等于阈值 $C$，求最小非负根并验证第一处穿越。
  \item 500 点在 95\% 下有 25 个尾部观察，状态 warn；99\% 下只有 5 个，应按默认阈值拒绝。总样本量没有改变这一区别。
  \item 课程二阶例的线性/非线性单位损失为 $4.4/4.016$。全重估应同时更新现货、曲线、波动率曲面和剩余期限，并报告模型失败。
  \item 四点样本在 99\% 下有效尾部数为 0.04，任何 ES 数字几乎只是最大值重命名。报告应拒绝或明确标成教学演示。
  \item $s^*$ 是沿已声明方向的条件阈值。只有另建冲击概率模型，才可能讨论达到该阈值的概率；方向选择本身也有模型风险。
\end{enumerate}

\section*{逐题推导与核对}
\begin{enumerate}[leftmargin=*]
  \item VaR 是给定置信度的分位点，回答“损失阈值在哪里”；ES 是超过该阈值后的平均，回答“尾部平均多坏”；历史压力重演联合冲击，假设压力指定情景，反向压力从资本/流动性阈值倒推所需冲击。它们的输入、概率解释和失败边界不同。
  \item 令损失分布分位点为 $q_\alpha$。ES 可写为 $\frac1{1-\alpha}\int_\alpha^1q_u\,du$；若离散样本在 $q_\alpha$ 处有质量，先把严格超过分位点的尾部全部纳入，再按剩余概率质量部分纳入边界观察，最后除以 $1-\alpha$。因此不是简单取“最后几个样本的平均”。
  \item 二阶损失近似 $L(sx)=-s d^Tx-\frac12s^2\sum_ig_ix_i^2$。令 $A=\frac12\sum_ig_ix_i^2$、$B=d^Tx$，解 $-Bs-As^2=C$，即 $As^2+Bs+C=0$；取满足 $s\ge0$ 的最小根，代回原损失并检查邻近点，确保是第一次穿越阈值而非另一支根。
  \item $N=500$ 时 95\% 尾部有效数 $(1-.95)N=25$，可标为 warn；99\% 只有 5 个，低于预先设定的最小分辨率，应拒绝或降级。比较两置信度时还要列分位点索引、边界权重和 bootstrap 区间，不能只把两个数字并排。
  \item 线性重估只用 Delta，忽略 Gamma、Vega 和期限变化；全重估要同步更新现货、曲线、波动率曲面、股息和剩余期限。把两种损失按同一状态逐情景列出，得到 $4.4$ 与 $4.016$，差异即为非线性重估证据，不是统计噪声。
  \item 四点样本在 99\% 下尾部质量只有 $0.04$ 个观测，任何 ES 几乎等于最大损失且区间由单点决定。报告应返回 warn/reject，说明样本量、有效尾部数和分位点分辨率；不能把一个最大值重新命名为稳健 ES。
  \item 反向压力的 $s^*$ 是沿给定方向 $x$ 的条件阈值，不是随机冲击的概率。要谈危机概率，必须另建冲击方向/幅度分布并积分；方向选择、二阶近似和非线性重估本身也应作为模型风险报告。
\end{enumerate}

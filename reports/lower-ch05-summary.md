# 组合与风险可复现研究包

- 协方差 oracle：$\sigma_1^2=0.040000$，$\sigma_{12}=0.010000$，$\sigma_2^2=0.090000$；因子分解与直接矩阵一致。
- 优化：二资产最小方差权重为 (0.727273, 0.272727)；加入协方差 ridge 后为 (0.700000, 0.300000)，说明输入扰动会改变解。
- 再平衡台账：目标权重 (0.600000, 0.400000)，双边换手 0.400000，线性成本 40.00；最大权重与可交易约束在搜索中生效。
- 风险：75% 经验 VaR 为 2.000000，严格尾部 ES 为 4.000000，压力情景损失为 7.000000。
- 失败边界：非正定协方差、不可交易资产变仓、尾部样本不足分别拒绝；正态轻尾近似不能替代经验尾部和压力情景。
- 限制：两资产网格不是生产优化器；线性成本忽略冲击与容量；历史 VaR/ES 不保证未来尾部稳定。
- 复现命令：`uv run python notebooks/lower/ch05_portfolio_risk.py evidence/lower-ch05/oracle.json`。

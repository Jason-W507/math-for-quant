# v0.5.0 — 教材源码与本地出版流程整理版

本版本是 2026-08-02 的小版本更新，重点是让教材源码、教学 notebook 和出版流程直接、可复现：

- 教学 notebook 直接以仓库跟踪的 `.ipynb` 文件维护；删除重复执行 notebook 和 LaTeX 的 CI 层，编辑时直接验证受影响文件；
- 用单一的 `tools/publish.ps1` 入口调用 `latexmk` 编译上册、下册和共享答案册，并在 `-Release` 下直接打包跟踪的 notebook；
- 删除不再承担教学或出版职责的 Python 构建、测试和契约编排脚本；
- 润色上下册正文、术语、图形说明及开发文档，并修复 MiKTeX 缺失的 `fixtounicode` 依赖。

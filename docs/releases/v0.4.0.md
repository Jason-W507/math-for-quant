# v0.4.0 — 视觉与笔面试训练增强版

本版本集中完成三项教材升级：

- 下册按知识耦合度重组为 9 个方向章节，机器学习与 AI 形成“树模型—现代与前沿 AI—研究设计”三章主线，并补入 CNN、序列模型、Transformer/LLM、GNN 与 DRL；
- 上下册统一采用来源驱动的可视化体系，系统补充概率、线性代数、优化、机器学习、衍生品、组合风险和微观结构图形；
- 新增 Brainteaser 学习单元，并将《A Practical Guide to Quantitative Finance Interviews》冻结的 146 个具名目录条目中的 73 个映射为章末笔面试题，严格达到总题量 50% 覆盖率。

73 道来源映射题均有唯一主归属、独立中文改写、题型与限时元数据、完整答案和逐题追问。覆盖率分母固定为全部 146 条，不使用另行筛选的“高重要度”子集缩小口径。

发行资产为上册、下册和共享答案册三份 PDF。可执行 notebook 与源码继续保存在仓库中，不再让课程内部契约阻塞 PDF 发布。

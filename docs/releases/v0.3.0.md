# v0.3.0 — 完整双册与共享答案

本版本把《量化研究数学》整理为可直接下载、构建和复核的双册教程：

- 上册：17 个通用数学与研究证据学习单元；
- 下册：六条方向路线、18 个正式学习单元；
- 共享答案册：统一收录上下册 35 个正式学习单元的完整答案；
- executed notebook 压缩包与带 SHA-256、许可、版本和来源的发行清单。

下册路线包括多因子与计量、时间序列与统计套利、机器学习 Alpha、衍生品定价与对冲、组合与风险、高频/微观结构与执行。每条路线均包含模型与推导、估计与数值实现、样本外研究与交易摩擦/Capstone。

发行资产由同一 Git commit 通过 `latexmk` 和完整 release seam 构建；请使用 `release-manifest.json` 核对哈希与许可。

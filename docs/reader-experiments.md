# 配套实验阅读指南

先阅读对应章节的问题、定义和例题，再打开同名 notebook。每个实验可以从第一格顺序运行；正文中的小算例有助于预判结果，重复模拟则用来观察抽样波动。

## 打开实验

在已安装 uv 的环境中，进入仓库根目录。下面第二条命令同时提供 Jupyter Notebook 界面：

```bash
uv sync
uv run --with notebook jupyter notebook
```

打开 `notebooks/upper/` 或 `notebooks/lower/` 中的文件。只阅读正文与答案册时，无须安装运行环境。若在 VS Code 等编辑器中打开 notebook，应选择本项目环境对应的 Python 内核。

## 修改与解释

先完整运行默认例子，再一次改变一个参数或一组有明确含义的数据。比较中间量与图形：改变的是数学对象、数值近似，还是随机样本？修改模型时需留意正文条件，例如满列秩公式无法原样用于秩亏矩阵。

修改前面的数据后，应重新运行后续各格。结果取决于旧变量时，可重启内核并从头运行。随机模拟的具体小数可能变化；解析关系、误差大小与分布形状比复现某一串小数更有解释力。

练习反馈收录在对应 notebook 或共享答案册中。环境安装、出版构建与维护问题另见 `development.md`，不属于数学练习内容。

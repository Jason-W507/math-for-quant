# 第二轮课程评审修订（2026-09-08）

本轮对应“课程评审建议”中 2026-09-08 的复审意见，聚焦估计方法的衔接、具体错误、算例位置及统计套利实验。此前已完整展开的投影、PCA、条件期望和随机积分证明继续保留。

| 评审问题 | 本轮处理 |
|---|---|
| 第十章缺少估计量构造 | 增加似然定义、Bernoulli 内点与边界解、正态回归系数与方差 MLE、三点算例及条件密度分解；第十二章回指此节。 |
| 第六章基础概念过密 | 沿三点回归计算列空间、零空间、左零空间与行空间，解释参数空间和观测空间；完整计算两列 Gram–Schmidt 与回代。 |
| 病态被误写为绝对小奇异值 | 答案改为相对奇异值比，加入整体缩放和不均匀缩放两个对照；同步 Notebook。 |
| 修改原始矩阵为秩亏后实验失败 | SVD 显示相对阈值与保留方向；只有满列秩时使用 QR 回代和正规方程，秩亏时显示最小范数解；验证默认、重复列和近共线三种输入。 |
| 分位数标签禁令过宽 | 区分历史固定阈值与逐期横截面目标，给出资产集合、并列处理及特征可得、标签实现、拟合三个时间；增加对应题解。 |
| 基础例子被追加在章末 | 置信区间移到渐近理论前；标量两层网络移到矩阵反向传播前；离散 ES 移到定义后；ridge 谱推导移入 ridge 部分，单列算例紧接 lasso。 |
| 旧固定输出与重复段落 | 删除 MSE 输出字符串、未完整定义的模拟小数、旧 ridge/lasso 数值、统计套利确定性回归输出；合并尾部风险的重复压力、重估和治理段落。 |
| 统计套利只比较功效 | 新增 80 与 300 点独立随机游走的无协整对照，保留共同趋势模型的样本量与持续性比较。 |
| 模拟频率缺少精度说明 | 每组默认 300 次独立重复，显示模拟标准误及 Wilson 区间；说明边界频率的零插件标准误不等于没有不确定性。 |
| 噪声尺度混淆 | 固定同一随机游走与标准化创新，比较 0.5 与 2 的尺度，推导参数误差与残差缩放、固定规格统计量不变；正文、实验和题解对应。 |
| 下载版与源码混淆 | README 明确本轮本地 PDF、当前源码与 Release 资产的区别，本轮未更新外部 Release。 |

## 验证与观察

- 三本改动 Notebook 全部从头执行；线性代数额外执行重复列和近共线输入，共五个运行情形通过。核对 SVD、伪逆与最小二乘结果，并确认内嵌图像存在。
- 似然实验得到 Bernoulli MLE 0.7、似然比约 2.27693，正态三点方差 MLE 1/18、无偏估计 1/6。
- 本次固定随机设计下，无协整对照的拒绝频率约为 7.33%（80 点）和 3.33%（300 点），对应 Wilson 区间均包含名义 5%。这只是该模拟设计的有限次数结果，不证明检验在所有模型下精确控制大小。
- 配对尺度实验的斜率误差分别约 0.00642、0.02568；两次统计量均约 -6.10871，差约 2.7e-15。它支持本章纯尺度变换推导的数值展示，不代表噪声在其他生成模型中无影响。
- 三册 PDF 成功编译：上册 144 页、下册 131 页、答案册 62 页。抽查新增似然推导、网络开篇、离散 ES 页面及模拟图，未见裁切。最终编译无缺字或未定义引用；上册原有第一章、分布变换例与术语表仍有三处轻微超宽提示，新增条件数答案的超宽已修复。
- 课程资产检查、模板文件检查和 `git diff --check` 通过。正文风格检查仍有原有七条段首标题密度提示。本轮未把未改动的其余 Notebook 重新执行结果冒充新验证。
- 统计套利选读 Johansen 调用在本机仍出现库内部 ComplexWarning，但返回结果且后续实验正常；本轮新增 Engle–Granger 比较不依赖该输出。

# 教程不承载维护验收要求

状态：采用。

用户在 2026-09-07 的逐章修订中明确要求：日志、哈希和验收清单对教程没有必要，应彻底移出，而非仅降低密度。

正文、练习、提示、答案和教学 notebook 不要求固定日志、退出码、字节哈希、预设输出、打包或验收状态。相关维护资料留在 docs/maintenance/，不作为书内附录。维护程序和数据核对仍可独立存在。

教程保留数学定义、推导、例题、反例、可修改参数的计算，以及对抽样误差、数值误差、信息时点和交易成本的解释。解析参照用于理解计算，不用于要求读者锁定某次随机结果。

本决定补充 ADR 0009；学习效果通过读者能否推导和解释来衡量，不通过工程材料是否齐全来衡量。

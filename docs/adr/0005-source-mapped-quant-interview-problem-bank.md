# 绿皮书题目采用来源映射改写与固定覆盖台账

本书将完整登记 *A Practical Guide to Quantitative Finance Interviews* 的 146 个具名目录条目，并以全部 146 条为冻结分母，至少覆盖其中 50%，不得通过另行筛选“高重要度集合”缩小分母。研究相关性、面试常见度、知识迁移性和章节匹配度四轴评分只用于安排优先次序，不改变覆盖率口径。由于项目没有书面转载许可，入选题保留核心考点、难度和原题名映射，但重写中文题面并独立编写完整面试解答；现有四级练习中重复或偏弱题目可被替换，每道原题只有一个主归属。完整评分与映射台账保存在仓库，书内只发布覆盖摘要和索引；下册另设位于六路线之前的 Brainteaser 完整学习单元。

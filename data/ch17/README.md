# Chapter 17 synthetic research rows

SPDX-License-Identifier: CC0-1.0

This three-row dataset is an original, synthetic teaching fixture. It contains no real security, venue, return, or trading-cost observation. The four timestamp columns encode event, availability, decision, and target-start times; `gross_return` is an additive contribution on a common capital base.

The fixture exists only to make the audit gates hand-calculable. It does not estimate market performance, transaction costs, capacity, or A-share rules.

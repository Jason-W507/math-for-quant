# Coinbase Exchange market-data provenance

This frozen snapshot was retrieved on 2026-07-31 from the public Coinbase
Exchange REST endpoint `GET /products/BTC-USD/trades`. The API documents
`side` as the maker side. The snapshot is included solely as a small,
reproducible teaching input; it is not an open-licensed oracle and does not
represent a complete market feed.

- API documentation: https://docs.cdp.coinbase.com/api-reference/exchange-api/rest-api/products/get-product-trades
- Coinbase terms: https://www.coinbase.com/legal/user_agreement/united_states
